# Estilo de nodos

> **Versión:** v0.2 (beta)

Puedes personalizar la apariencia de cualquier nodo cambiando su color de fondo, añadiendo un icono o estableciendo un indicador de estado.

---

## Abrir el Node Editor

**Haz clic** en cualquier nodo para abrir el panel **Node Editor** a la derecha de la pantalla.

El panel se divide en estas secciones:

1. **Node Info** — editar la etiqueta de texto
2. **Actions** — Add Child, Add Sibling, Delete
3. **Background Color** — 8 colores preestablecidos
4. **Icon** — 24 iconos disponibles
5. **Status** — Pending, In Progress, Done
6. **Keyboard Shortcuts** — referencia rápida de atajos

## Color de fondo

MindMapper ofrece **8 colores preestablecidos**. Haz clic en cualquier muestra para aplicarlo al nodo seleccionado.

| Color | Código hex |
|---|---|
| Azul | `#60A5FA` |
| Verde | `#34D399` |
| Amarillo | `#FBBF24` |
| Rojo | `#F87171` |
| Morado | `#A78BFA` |
| Naranja | `#FB923C` |
| Rosa | `#EC4899` |
| Verde azulado (teal) | `#14B8A6` |

[SCREENSHOT: Las muestras de color en la sección Background Color del Node Editor]

> 💡 **Consejo:** Usa los colores de forma sistemática para categorizar ideas — por ejemplo, azul para tareas, verde para elementos completados, rojo para bloqueos.

## Icono

Asigna un pequeño icono a un nodo para darle significado visual de un vistazo. MindMapper incluye **24 iconos**:

| Grupo | Iconos |
|---|---|
| Formas / símbolos | Circle, Star, Heart, Zap, Flag, Award |
| Estado | CheckCircle, AlertCircle, XCircle, Info, Target |
| Contenido | Folder, File, Book, Bookmark |
| Personas | User, Users, MessageSquare, Mail |
| Tiempo / datos | Calendar, Clock, TrendingUp, Activity, BarChart, PieChart |
| Ideas | Lightbulb |

Haz clic en un icono del Node Editor para asignarlo. Haz clic en el **mismo icono de nuevo** para eliminarlo.

## Estado

La sección **Status** marca el estado de progreso de un nodo con un punto de color que aparece sobre el lienzo.

| Estado | Color del punto | Significado |
|---|---|---|
| (ninguno) | — | Sin estado establecido |
| Pending | Gris | No comenzado |
| In Progress | Amarillo | En curso |
| Done | Verde | Completado |

Haz clic en un botón de estado para establecerlo. Haz clic en el **mismo botón de nuevo** para quitarlo y volver a "sin estado".

[SCREENSHOT: Los botones de estado en el Node Editor y un nodo con un punto amarillo de "In Progress" visible en el lienzo]

## Combinar color + icono + estado

Puedes mezclar cualquier combinación. Algunos ejemplos:

| Color | Icono | Estado | Significado |
|---|---|---|---|
| Rojo | AlertCircle | In Progress | Incidencia urgente en curso |
| Verde | CheckCircle | Done | Tarea completada |
| Azul | Folder | — | Categoría o agrupación |
| Amarillo | Clock | Pending | Urgente, aún sin comenzar |
