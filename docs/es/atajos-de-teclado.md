# Atajos de teclado

> **Versión:** v0.2 (beta)

Esta es la referencia completa de todos los atajos de teclado disponibles en MindMapper.

> 💡 **Consejo:** Pulsa **Ctrl + /** en cualquier momento dentro de la aplicación para abrir el panel de referencia rápida sin salir de tu mapa.

---

## Operaciones de archivo

| Atajo | Acción |
|---|---|
| **Ctrl + N** | Nuevo mapa (abre el selector de plantillas: Blank o Brainstorming) |
| **Ctrl + O** | Abrir… |
| **Ctrl + S** | Guardar |
| **Ctrl + Shift + S** | Guardar como… |
| **Ctrl + E** | Exportar a PDF |

---

## Edición

| Atajo | Acción |
|---|---|
| **Ctrl + Z** | Deshacer |
| **Ctrl + Y** | Rehacer |
| **Ctrl + X** | Cortar |
| **Ctrl + C** | Copiar |
| **Ctrl + V** | Pegar |
| **Ctrl + A** | Seleccionar todo |

---

## Trabajar con nodos

| Atajo | Acción |
|---|---|
| **Tab** | Añadir un nodo hijo al nodo seleccionado |
| **Enter** | Añadir un nodo hermano al nodo seleccionado |
| **Suprimir** o **Retroceso** | Eliminar el nodo seleccionado (y todos sus hijos) |
| **Doble clic** | Editar el texto del nodo seleccionado |
| **Enter** (mientras se edita) | Confirmar la edición de texto |
| **Escape** (mientras se edita) | Cancelar la edición de texto |

---

## Vista y navegación

| Atajo | Acción |
|---|---|
| **Ctrl + +** | Acercar (zoom in) |
| **Ctrl + −** | Alejar (zoom out) |
| **Ctrl + 0** | Restablecer zoom al 100 % |
| **Ctrl + 1** | Ajustar todos los nodos a la pantalla |
| **Ctrl + T** | Cambiar tema (claro ↔ oscuro) |
| **F11** | Activar/desactivar pantalla completa |

---

## Búsqueda

| Atajo | Acción |
|---|---|
| **Ctrl + F** | Abrir / cerrar la barra de búsqueda |
| **Enter** (en la barra de búsqueda) | Ir al siguiente resultado |
| **Shift + Enter** (en la barra de búsqueda) | Ir al resultado anterior |
| **Escape** (en la barra de búsqueda) | Cerrar la barra de búsqueda |

---

## Ayuda y utilidades

| Atajo | Acción |
|---|---|
| **Ctrl + /** | Mostrar el panel de referencia de atajos de teclado |
| **F12** | Abrir las herramientas de desarrollo (útil para informes de errores) |

---

## Referencia de la barra de menú

Para acciones que no tienen atajo de teclado, usa la barra de menú en la parte superior de la ventana:

- **File (Archivo)** → New, Open…, Save, Save As…, Export > [Export to PDF…, Export to JSON…], Exit
- **Edit (Edición)** → Undo, Redo, Cut, Copy, Paste, Select All
- **View (Vista)** → Zoom In, Zoom Out, Reset Zoom, Fit to Screen, Toggle Theme
- **Help (Ayuda)** → Documentation, Keyboard Shortcuts, About MindMapper
