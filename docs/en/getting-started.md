# Getting Started with MindMapper

> **Version:** v0.2 (beta) · **Estimated read time:** ~3 minutes

Welcome! This guide takes you from zero to your first mind map in just a few minutes.

---

## What is a Mind Map?

A mind map is a visual diagram that organises your ideas around a central topic. Each idea branches out to related sub-ideas, helping you think clearly, plan projects, and remember information.

[SCREENSHOT: A sample mind map with a central node and several coloured branches]

---

## 1. Launch MindMapper

Open the application. On first launch, MindMapper greets you with a **Welcome** map so you can immediately see what a mind map looks like.

[SCREENSHOT: MindMapper on first launch showing the Welcome map]

---

## 2. Create Your First Map

1. Click the **New** button in the toolbar (top-left) and choose **Blank** from the drop-down menu.  
   *Or press* **Ctrl + N**.

2. If you have unsaved work, a dialog appears — click **Continue** to proceed.

3. A new map opens with a single node labelled **Main Idea**.

[SCREENSHOT: A blank map with the "Main Idea" root node in the centre]

---

## 3. Name Your Central Idea

1. **Double-click** the **Main Idea** node on the canvas.
2. Type your central topic — for example, *"My Project Plan"*.
3. Press **Enter** to confirm.

---

## 4. Add Your First Branch

| What you want | How to do it |
|---|---|
| Add a child node (sub-idea) | Select a node → press **Tab** |
| Add a sibling node (same level) | Select a node → press **Enter** |
| Delete a node | Select a node → press **Delete** |

You can also click any node to open the **Node Editor** panel on the right, and use the **Add Child**, **Add Sibling**, or **Delete** buttons there.

[SCREENSHOT: The Node Editor panel showing the Add Child, Add Sibling, and Delete buttons]

---

## 5. Save Your Map

Press **Ctrl + S** to save.  
The first time you save, a dialog asks where to put the file. MindMapper saves in `.mindmap.json` format.

> 💡 **Tip:** Watch for the **orange dot** next to your map's name in the toolbar — it appears whenever there are unsaved changes.

---

## 6. Navigate the Canvas

| Action | How |
|---|---|
| Pan (scroll around) | Click and drag on any empty area |
| Zoom in / out | Mouse wheel, or **Ctrl + +** / **Ctrl + −** |
| Fit everything on screen | **Ctrl + 1**, or click **Fit to Screen** (bottom-right) |
| Reset zoom to 100 % | **Ctrl + 0** |

[SCREENSHOT: The zoom controls in the toolbar and the Fit to Screen / Reset View buttons in the bottom-right corner]
