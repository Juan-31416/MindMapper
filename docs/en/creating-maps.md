# Creating and Managing Maps

> **Version:** v0.2 (beta)

This guide explains how to create new mind maps, open existing ones, and save your work safely.

---

## Creating a New Map

Click the **New** button in the toolbar (top-left) to open the template chooser, or press **Ctrl + N**.

### Option A — Blank Map

Starts with a single root node labelled **Main Idea**. Use this when you want to build a map entirely from scratch.

1. Click **New** → **Blank**.

[SCREENSHOT: The New button drop-down showing "Blank" and "Brainstorming" options]

### Option B — Brainstorming Template

Gives you a pre-built structure with four branches to jump-start your thinking:

- 💡 **Main Idea** (root)
  - 📋 **Planning** → Research A, Research B
  - 🔍 **Research** → Analysis A, Analysis B
  - ⚙️ **Implementation** → Phase 1, Phase 2
  - ✅ **Review** → Testing, Feedback

1. Click **New** → **Brainstorming**.

[SCREENSHOT: A new map using the Brainstorming template with all its pre-built branches]

## Unsaved Changes Warning

If you have unsaved work when you try to create or open another map, MindMapper shows a confirmation dialog:

- **Cancel** — go back without losing anything
- **Continue** — discard unsaved changes and proceed

> 💡 **Tip:** The **orange dot** next to your map's name in the toolbar tells you there are unsaved changes.

[SCREENSHOT: The "Unsaved Changes" confirmation dialog]

## Opening an Existing Map

1. Click **Open** in the toolbar, or press **Ctrl + O**.
2. A file dialog opens. Select your `.mindmap.json` file and click **Open**.

> **Note:** MindMapper's native format is `.mindmap.json`. You can also import `.json`, `.md`, and `.markdown` files — see [Importing and Exporting](import-export.md).

---

## Saving Your Map

### Save (overwrite current file)

Press **Ctrl + S**, or click the **Save** button in the toolbar.

If this map has not been saved before, a dialog asks where to save it and what to name it.

### Save As… (create a copy)

Press **Ctrl + Shift + S**, or go to **File > Save As…**

This saves a copy of the current map under a new name or location, leaving the original file unchanged.

---

## Closing MindMapper

When you close the application with unsaved changes, a dialog gives you three choices:

- **Cancel** — stay in the application
- **Close Without Saving** — exit and discard changes
- **Save and Close** — save first, then exit
