# Keyboard Shortcuts

> **Version:** v0.2 (beta)

This is the complete reference for all keyboard shortcuts in MindMapper.

> 💡 **Tip:** Press **Ctrl + /** at any time inside the app to open a quick-reference panel without leaving your map.

---

## File Operations

| Shortcut | Action |
|---|---|
| **Ctrl + N** | New map (opens template chooser: Blank or Brainstorming) |
| **Ctrl + O** | Open… |
| **Ctrl + S** | Save |
| **Ctrl + Shift + S** | Save As… |
| **Ctrl + E** | Export to PDF |

---

## Edit

| Shortcut | Action |
|---|---|
| **Ctrl + Z** | Undo |
| **Ctrl + Y** | Redo |
| **Ctrl + X** | Cut |
| **Ctrl + C** | Copy |
| **Ctrl + V** | Paste |
| **Ctrl + A** | Select All |

---

## Working with Nodes

| Shortcut | Action |
|---|---|
| **Tab** | Add a child node below the selected node |
| **Enter** | Add a sibling node next to the selected node |
| **Delete** or **Backspace** | Delete the selected node (and all its children) |
| **Double-click** | Start editing the selected node's text |
| **Enter** (while editing) | Confirm the text edit |
| **Escape** (while editing) | Cancel the text edit |

---

## View and Navigation

| Shortcut | Action |
|---|---|
| **Ctrl + +** | Zoom in |
| **Ctrl + −** | Zoom out |
| **Ctrl + 0** | Reset zoom to 100 % |
| **Ctrl + 1** | Fit all nodes to screen |
| **Ctrl + T** | Toggle theme (light ↔ dark) |
| **F11** | Toggle fullscreen |

---

## Search

| Shortcut | Action |
|---|---|
| **Ctrl + F** | Open / close the search bar |
| **Enter** (in search bar) | Jump to the next matching node |
| **Shift + Enter** (in search bar) | Jump to the previous matching node |
| **Escape** (in search bar) | Close the search bar |

---

## Help and Utilities

| Shortcut | Action |
|---|---|
| **Ctrl + /** | Show keyboard shortcuts reference panel |
| **F12** | Open developer tools (useful for bug reports) |

---

## Menu Bar Reference

For actions that do not have a keyboard shortcut, use the menu bar at the top of the window:

- **File** → New, Open…, Save, Save As…, Export > [Export to PDF…, Export to JSON…], Exit
- **Edit** → Undo, Redo, Cut, Copy, Paste, Select All
- **View** → Zoom In, Zoom Out, Reset Zoom, Fit to Screen, Toggle Theme
- **Help** → Documentation, Keyboard Shortcuts, About MindMapper
