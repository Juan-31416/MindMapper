# Styling Nodes

> **Version:** v0.2 (beta)

You can customise the appearance of any node by changing its background colour, adding an icon, and setting a status indicator.

---

## Opening the Node Editor

**Click** any node to open the **Node Editor** panel on the right side of the screen.

The panel is divided into sections:

1. **Node Info** — edit the text label
2. **Actions** — Add Child, Add Sibling, Delete
3. **Background Color** — 8 colour presets
4. **Icon** — 24 icon choices
5. **Status** — Pending, In Progress, Done
6. **Keyboard Shortcuts** — quick reference

## Background Colour

MindMapper offers **8 preset colours**. Click any swatch to apply it to the selected node.

| Colour | Hex Code |
|---|---|
| Blue | `#60A5FA` |
| Green | `#34D399` |
| Yellow | `#FBBF24` |
| Red | `#F87171` |
| Purple | `#A78BFA` |
| Orange | `#FB923C` |
| Pink | `#EC4899` |
| Teal | `#14B8A6` |

[SCREENSHOT: The Background Color swatches in the Node Editor]

> 💡 **Tip:** Use colours consistently to categorise ideas — for example, blue for tasks, green for completed items, red for blockers.

## Icon

Assign a small icon to a node to add visual meaning at a glance. MindMapper includes **24 icons**:

| Group | Icons |
|---|---|
| Shapes / symbols | Circle, Star, Heart, Zap, Flag, Award |
| Status | CheckCircle, AlertCircle, XCircle, Info, Target |
| Content | Folder, File, Book, Bookmark |
| People | User, Users, MessageSquare, Mail |
| Time / data | Calendar, Clock, TrendingUp, Activity, BarChart, PieChart |
| Ideas | Lightbulb |

Click an icon in the Node Editor to assign it. Click the **same icon again** to remove it.

## Status

The **Status** section marks the progress state of a node with a coloured dot that appears on the canvas.

| Status | Dot Colour | Meaning |
|---|---|---|
| (none) | — | No status set |
| Pending | Grey | Not yet started |
| In Progress | Yellow | Work underway |
| Done | Green | Completed |

Click a status button to set it. Click the **same button again** to clear the status and return to none.

[SCREENSHOT: The Status buttons in the Node Editor and an example node showing a yellow "In Progress" dot on the canvas]

## Combining Colour + Icon + Status

You can mix any combination. A few examples:

| Colour | Icon | Status | Meaning |
|---|---|---|---|
| Red | AlertCircle | In Progress | Urgent issue in progress |
| Green | CheckCircle | Done | Completed task |
| Blue | Folder | — | Category or group |
| Yellow | Clock | Pending | Time-sensitive, not started |
