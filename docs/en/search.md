# Searching Your Map

> **Version:** v0.2 (beta)

The search bar helps you find any node quickly, even in a large or complex map.

---

## Opening and Closing the Search Bar

| Action | How |
|---|---|
| Open search | Press **Ctrl + F** |
| Close search | Press **Escape**, or click the **×** button in the search bar |

[SCREENSHOT: The search bar open at the top of the canvas]

---

## How to Search

1. Press **Ctrl + F** to open the search bar.
2. Type at least **2 characters** — results appear as you type.
3. Every matching node is highlighted with a **gold border** on the canvas.

[SCREENSHOT: Several nodes on the canvas highlighted with gold borders after a search]

---

## Navigating Between Results

If your search returns more than one match, you can step through them:

| Action | Shortcut |
|---|---|
| Go to next result | **Enter** |
| Go to previous result | **Shift + Enter** |

---

## How Matching Works

MindMapper uses **fuzzy search** — it finds nodes even when your text is not an exact match. For example, searching `"projct"` may still find a node labelled `"Project Plan"`.

> **Note:** A minimum of **2 characters** must be typed before the search begins.

---

## Collapsed Branches

If a matching node is inside a collapsed branch (one where you clicked **−** to hide children), MindMapper **automatically expands** that branch so you can see the result.

---

## Tips

- Search is **case-insensitive** — `"PLAN"` and `"plan"` return the same results.
- Clear the search box (or press **Escape**) to remove all highlights and return to the normal view.
- The search bar placeholder reads *"Buscar nodos… (Esc para cerrar)"* in the current v0.2 build. This will be localised in a future release.
