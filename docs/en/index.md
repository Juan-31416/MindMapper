## Quick reference

### Most-used shortcuts

| Shortcut | Action |
|---|---|
| `Tab` | Add child node |
| `Enter` | Add sibling node |
| `Double-click` | Edit node text |
| `Delete` | Delete node |
| `Ctrl+S` | Save |
| `Ctrl+Z` / `Ctrl+Y` | Undo / Redo |
| `Ctrl+F` | Search |
| `Ctrl+1` | Fit map to screen |

→ Full list: [Keyboard shortcuts](keyboard-shortcuts.md)

## Help inside the app

You can open the keyboard shortcut reference at any time from inside MindMapper:

- **Menu:** Help → Keyboard Shortcuts
- **Shortcut:** `Ctrl+/`
